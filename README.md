# CyberShield Ethiopia — Release 2 (PostgreSQL & Authentication)

Multilingual (English / Afaan Oromoo / አማርኛ), privacy-first cybersecurity awareness platform.
React + Vite frontend, FastAPI backend (loopback only), PostgreSQL 16 database with Alembic migrations, secure Argon2id password authentication, guest mode, and consent-controlled cloud learning progress synchronization.

---

## Architecture & Privacy Model

- **Dual-Mode Operation**:
  - **Guest Mode (Default)**: All educational modules (M1 Link Checker, M2 Password Tools, M3 Incident Report Assistant, M4 Simulation, and M5 Learn) are fully functional offline without creating an account or logging in. Local guest activity is never sent to the server.
  - **Account Mode (Optional)**: Users can create an account to securely synchronize and back up their M5 course progress across devices.
- **Privacy Guarantees**:
  - Cloud learning progress sync is **STRICTLY OFF** by default and requires explicit user consent in the Account settings.
  - Even with cloud sync enabled, **ONLY** high-level learning progress is stored (active level number, unlocked level list, and completion score/stars).
  - **NEVER Stored**: Passwords checked or generated by M2, submitted URLs from M1, sensitive report text from M3, individual quiz question answers, or external tracking telemetry.
- **Authentication Security**:
  - Passwords hashed using **Argon2id** (`time_cost=2`, `memory_cost=64MB`, `parallelism=1`, 32-byte hash). Plaintext passwords are never stored or logged.
  - High-entropy revocable sessions stored as SHA-256 hashes in `user_sessions`.
  - Sessions issued via `HttpOnly`, `SameSite=Lax`, environment-controlled `Secure` cookies (`cybershield_session`), preventing XSS access.
  - Sliding-window rate limiting on login and registration endpoints to mitigate brute force.
  - Constant-time-like generic error responses for authentication failures to prevent user enumeration.

## PostgreSQL Database Setup & Migrations

1. Ensure PostgreSQL is running on `127.0.0.1:5432`.
2. Create the development and test databases:
   ```bash
   createdb -h 127.0.0.1 -p 5432 -U postgres cybershield_dev
   createdb -h 127.0.0.1 -p 5432 -U postgres cybershield_test
   ```
3. Apply Alembic migrations against `cybershield_dev`:
   ```bash
   cd backend
   .\.venv\Scripts\alembic.exe upgrade head
   ```
4. Verify migration rollback and re-apply:
   ```bash
   .\.venv\Scripts\alembic.exe downgrade -1
   .\.venv\Scripts\alembic.exe upgrade head
   ```

## Running the Application

### 1. Build Frontend
```bash
cd frontend
npm.cmd run build
```

### 2. Start Backend Server
```bash
cd backend
.\.venv\Scripts\python.exe run.py
```
Open **http://127.0.0.1:8000** in your browser.

## Known Limitations

- **Machine Learning Pedagogical Validation**: The Journey adaptive ML model (`SoftmaxClassifier`) was trained and evaluated on an isolated synthetic pipeline dataset (`DATASET_LIMITATION_STATEMENT`). It demonstrates empirical lift over baseline on synthetic distributions, but real-world learner efficacy remains subject to prospective pedagogical validation. Real-world validation must not be claimed without authorized field studies.
- **Conversational AI Online Provider**: By default, the AI Assistant operates 100% offline using verified local knowledge. When external AI is not configured (`CYBERSHIELD_ASSISTANT_PROVIDER=none`), it truthfully reports `ONLINE_UNAVAILABLE` rather than fabricating external model responses. External transmission strictly requires explicit, informed user consent.
- **Email Verification**: Initial implementation uses local format and uniqueness validation without requiring external SMTP/email delivery service.
- **Reporting Channels**: Official Ethiopian reporting channels list is intentionally empty pending verified regulatory channels per FR-22.
- **Linguistic Review**: Afaan Oromoo and Amharic translations are complete draft translations labelled "awaiting review" in the interface.
- **Client Storage Policy**: `localStorage` is strictly restricted to storing only language preference code; authentication credentials are never stored in browser storage.
